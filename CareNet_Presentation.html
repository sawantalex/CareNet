☁️ Deployment
Production-Ready on Vercel
1

Clone & Install

Clone repo, install Python deps via pip install -r requirements.txt and frontend via npm install

2

Configure Environment

Set .env with SECRET_KEY, DATABASE_URL, and API settings in the backend/ folder

3

Run Locally

Backend: uvicorn app.main:app --reload on port 8000 · Frontend: npm run dev on port 5173

4

Deploy to Vercel

Push to GitHub → Vercel auto-builds frontend as static + backend as serverless via api/index.py
